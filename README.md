### 👋 About me
 
Full-stack developer in training at kood/Sisu, a 24-month project-based programme built on independent and team work with peer code review. I've completed the core Go and JavaScript modules, as well as a 6-month AI specialisation, and am currently in the DevOps specialisation.
 
I have a PhD (metabolomics, systems biology, and mass spectrometry) from Oxford, with postdoctoral research from Imperial College London, the Francis Crick Institute, and the National University of Singapore.
 
🌱 Currently working with Go, TypeScript, Python, React, PostgreSQL, and Docker, to mention a few, building production-style applications independently and in teams.
 
🚀 **Featured project with publicly available code: [Ella's Corner](https://github.com/MerjaR/ellas-corner)**
A server-rendered Go web application for community-sourced baby product recommendations. Originally a book discussion forum built on the Go standard library alone, reworked into a user-centred platform with authentication, item filtering, profile management, secure session handling, image upload, donation indicators, a SQLite backend, and Dockerized deployment. Unit and integration tests via Go's own testing package.
 
I keep my submitted kood/Sisu project code private, as requested by the programme, so it can't be copied. Access available on request.
 
For deployed projects, see **[The Wellness Platform AI specialiastion project](https://numbers-dont-lie.onrender.com/)**: Go, React, and PostgreSQL, with Claude Haiku as the AI backbone. RAG-based meal planning over a 546-recipe database with pgvector similarity search, 11 function-calling tools, sliding-window conversation context with automatic summarisation, and OAuth/2FA/JWT session handling.
